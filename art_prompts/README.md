# Подготовка иллюстраций для Mythoria

Список игр изменён. Мы оставили системы, в которых важнее генерировать класс, способности и характеристики, чем лицо персонажа.

Ранее подготовленные 290 описаний относились к старому каталогу и поэтому исключены из текущей версии. Их можно найти в истории GitHub.

Новые изображения желательно делать отдельными оригинальными персонажами на прозрачном фоне, без текстов и чужих логотипов. Для каждой поддерживаемой игры будем подбирать соответствующий стиль и экипировку.
