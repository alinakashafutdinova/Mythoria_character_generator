# Mythoria — генератор персонажей

Это мой курсовой проект по теме № 13 «Генератор персонажей».

Я сделала сайт, на котором можно выбрать ролевую игру, создать персонажа и сохранить его в свою коллекцию. Также можно искать персонажей, менять их данные и смотреть статистику.

Для работы я использовала Python, Flask, SQLite, HTML, CSS и JavaScript. В проекте есть 16 игровых систем. Их правила немного упрощены для учебной работы.

## Как запустить на MacBook

1. Установите Python 3.11 или новее, если его ещё нет.
2. Скачайте проект и распакуйте папку.
3. Откройте файл `run.command`. При первом запуске нужен интернет для установки библиотек.
4. После запуска откройте адрес, который появится в терминале (обычно http://127.0.0.1:5000).

Если файл не открывается, зайдите в папку проекта через терминал и выполните:

```bash
chmod +x run.command
./run.command
```

## Как запустить на Windows

Установите Python 3.11+, распакуйте проект и откройте `run.bat`.

## Что есть в проекте

- `characterlab/` — код приложения и генерации.
- `templates/` — страницы сайта.
- `static/` — оформление, картинки и JavaScript.
- `database/` — SQL-файлы и примеры данных.
- `tests/` — проверки работы программы.

Чтобы проверить программу, выполните `python -m pip install -r requirements-dev.txt`, затем `python -m pytest -q`.

## Как получить Windows .exe

На странице репозитория откройте **Actions** → **Сборка Mythoria для Windows** → последний успешный запуск. В разделе **Artifacts** скачайте `Mythoria-Windows`. Распакуйте архив целиком и откройте `Mythoria.exe`.

Сборка получена автоматически, но запуск файла на обычном компьютере с Windows ещё нужно проверить.

**Примечание.** Это учебная неофициальная программа, а не редактор персонажей от разработчиков перечисленных игр.
