# Mythoria

Мой курсовой проект по теме № 13 «Генератор персонажей».

Я делаю веб-приложение, в котором можно выбрать ролевую игру, создать персонажа и сохранить его в коллекцию.

Использую Python, Flask, SQLite, HTML, CSS и JavaScript.

Проект разрабатывается на MacBook. Инструкцию по запуску и остальные файлы добавляю по мере разработки.
