# Mythoria — генератор персонажей

Это мой курсовой проект по теме № 13 «Генератор персонажей».

Я сделала сайт, на котором можно выбрать ролевую игру, создать персонажа и сохранить его в свою коллекцию. Также можно искать персонажей, менять их данные и смотреть статистику. В каталоге игр есть поиск, а в генераторе — настройка параметров.

Для работы я использовала Python, Flask, SQLite, HTML, CSS и JavaScript. В проекте есть 16 игровых систем. Их правила немного упрощены для учебной работы.

## Как запустить на MacBook

1. Установите Python 3.11 или новее, если его ещё нет.
2. Скачайте проект и распакуйте папку.
3. Откройте файл `run.command`. При первом запуске нужен интернет для установки библиотек.
4. После запуска откройте адрес, который появится в терминале (обычно http://127.0.0.1:5000).

Если файл не открывается, зайдите в папку проекта через терминал и выполните:

```bash
chmod +x run.command
./run.command
```

## Как запустить на Windows

Установите Python 3.11+, распакуйте проект и откройте `run.bat`.

## Что есть в проекте

- `characterlab/` — код приложения и генерации.
- `templates/` — страницы сайта.
- `static/` — оформление, картинки и JavaScript.
- `database/` — SQL-файлы и примеры данных.
- `tests/` — проверки работы программы.

Чтобы запустить проверки, установите зависимости из `requirements-dev.txt` и выполните `python -m pytest -q`.

Готовую Windows-сборку можно скачать на GitHub в разделе **Actions** после успешной проверки. Она находится в файлах запуска под названием `Mythoria-Windows`. Если вы используете `.exe`, распакуйте всю папку, а не один файл.

**Примечание.** Это учебная неофициальная программа. Правила игр упрощены, а иллюстрации используются для оформления.

## Оформление сайта

Я сделала отдельные иллюстрации для главного экрана, промокарточки и нижнего блока. Для 16 игр добавила тематические портреты. Они выбираются из готового набора: сайт не рисует новые изображения при каждой генерации.

На страницах есть световые эффекты и анимации. Если на устройстве включено уменьшение движения, эффекты становятся спокойнее.
